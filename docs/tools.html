Valid reusable tools and KPIs

Judged by: sample size, effect with an interval excluding zero, whether it adds beyond trivial baselines (block height, OOP width/length/area, nearest defender, on-ball pressure), and reusability as code or a metric.

There is no xG, xGOT or xT in this dataset. Value fields are xshot, xthreat and EPV. Nothing below should be renamed as xG.

A. KPIs / diagnostics supported on all 20 matches

MetricEvidenceUse
Block height (low / medium / high)Shot rates ~18.5–18.7% low, ~9.0–9.3% medium, 6.0% highPrimary context split for every defensive report.
Defensive box area (OOP width × length), within blockShot phases ~148–166 m² smaller in the low block; area is the baseline coupled graphs had to beatCompactness diagnostic, always reported within block height — never as a standalone shot model (mean area alone does not rank teams).
On-ball pressure bandShot rate 2.2% (none) to 21.4% (very high)Context / engagement diagnostic. Do not read “more pressure = worse defending”: dangerous attacks attract pressure.
